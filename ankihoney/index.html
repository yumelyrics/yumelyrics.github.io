2 Pilih Note Type & Field

Ikon kunci di tiap field menandai field tersebut sebagai SUMBER (hanya dibaca AI untuk konteks, tidak diubah) — berbeda dari field target yang akan diisi hasil terjemahan.

+ Background Kartu Opsionalklik untuk buka/tutup▸

Ganti background tampilan kartu di Anki dengan foto, GIF, atau video sendiri. Berlaku untuk note type - yang sedang dipilih.

Penting jika note type ini sudah dipakai di deck lain yang sudah ada di Anki kamu: Anki hanya memperbarui tampilan note type saat import jika ada perubahan baru yang terdeteksi. Jika setelah import background tetap tidak muncul, hapus dulu deck versi lama dari Anki sebelum import ulang file yang baru.
🖼️ Pilih atau seret foto, GIF, atau video ke sini JPG/PNG/GIF/MP4, otomatis dikompres agar file .apkg tetap ringan
🖼️ Upload Gambar Fallback (Poster) untuk Video JPG/PNG. Ditampilkan instan sebelum video dimuat, agar transisi fade-in mulus [2]
Media tersimpan di dalam .apkg sehingga tetap muncul secara offline. Jika note type ini sudah dipakai di deck lain yang lebih lama, baca peringatan di atas terlebih dahulu.
Foto/Video harus tetap online agar background tidak hilang saat dipelajari. Media tidak tersimpan ke dalam .apkg (membutuhkan koneksi internet), tapi cara ini paling aman karena tidak menyentuh media/note type sama sekali.

+ Edit Template & Styling Kartu Opsionalklik untuk buka/tutup▸

Edit langsung HTML tampilan kartu Depan/Belakang & CSS-nya, lengkap dengan preview real-time. Berlaku untuk note type - yang sedang dipilih.

Field yang tersedia (klik untuk menyalin ke clipboard):
Preview Real-time
Preview ini menggunakan data dari note pertama di tabel & rendering handlebars sederhana (best-effort), termasuk menampilkan gambar & audio ASLI yang ada di dalam deck — mungkin tidak 100% sama dengan Anki asli untuk template yang kompleks, tapi cukup untuk mengecek perubahan HTML/CSS secara real-time.

Field yang ingin dirapihin (diberi baris baru per bagian):

Deck yang sedang terbuka otomatis menjadi deck utama. Pilih file .apkg kedua di bawah untuk digabung — note type & deck yang namanya sama akan disatukan, yang berbeda akan ditambahkan baru, dan ID yang bentrok otomatis diganti agar aman. Hasil gabungan baru tersimpan saat kamu klik Download di bawah.

Translate Otomatis klik untuk buka/tutup pengaturan ▶

Mode "Jelaskan Kosakata" membutuhkan AI yang dapat memahami instruksi — pilih salah satu dari OpenAI/Claude/Gemini/DeepSeek.

Instruksi ini sama konsepnya dengan "Instruksi Khusus Field" — bedanya AI-nya benar-benar memanggil API & hasilnya langsung ditaruh ke field Tujuan yang kamu pilih di bawah, tanpa perlu copy-paste manual.

Jika field Sumber hanya berisi kosakata tunggal (misal field Kosakata), field ini dapat diisi field lain yang berisi kalimat lengkapnya (misal SentKanji) — isinya HANYA DIBACA dan diberikan ke AI sebagai konteks tambahan.

Yang ditranslate hanya field yang dicentang tapi BUKAN ditandai kunci sumber. API key (jika diisi) hanya tersimpan lokal di browser kamu sendiri, dan teksnya dikirim LANGSUNG dari browser kamu ke server engine yang dipilih (bukan melalui server AnkiHoney).

Estimasi biaya/token: -

Kecocokan dicek best-effort (HTML/tanda baca diabaikan) — jika kartu yang "mirip" ternyata berbeda makna, hasil terjemahannya bisa ikut tersalin. Aktifkan hanya jika yakin duplikatnya benar-benar identik.

Baris per halaman

Tabel dibagi per halaman agar tidak lag saat deck besar — ini HANYA untuk tampilan, translate/jelaskan/copy-paste tetap berjalan ke SEMUA note yang dicentang, bukan hanya yang terlihat di halaman ini.

ID Preview Note Field (dapat diedit langsung)

4 Simpan Deck Baru

Setelah field diganti dengan hasil terjemahan, download ulang menjadi .apkg untuk diimport ke Anki kembali.

Jika nama deck ini diganti dari nama aslinya, saat diimport ke Anki akan membuat deck BARU dengan nama itu (bukan memperbarui nama deck yang lama). Deck lama tetap ada di Anki tapi kosong — bisa dihapus manual jika sudah tidak dibutuhkan.

Semua proses berjalan 100% di browser kamu — file .apkg tidak pernah dikirim ke server manapun.

Tempel Hasil Terjemahan

Tempel teks dengan format yang sama persis seperti saat disalin tadi (jangan hapus baris [[[ID:...]]] dan tag [NamaField] jika menggabungkan beberapa field), lalu klik Terapkan. Jika menerjemahkan per batch, tempel & terapkan satu batch dulu sebelum menyalin batch berikutnya.

Export ke PDF — Cetak Flashcard Fisik

Pilih field mana yang masuk ke sisi Depan & Belakang kartu (layout bersih & rapi, tanpa desain asli note type agar tidak berantakan saat dicetak kecil). Disusun jadi grid siap cetak, dibuka di tab baru. Di tab itu ada tombol "Cetak / Save as PDF" — klik jika sudah siap.

Kartu akan disusun otomatis sebanyak yang muat per halaman sesuai ukuran ini.

Mode "Samakan Posisi" (default): tiap kartu di halaman belakang ada di posisi grid yang SAMA dengan di halaman depan — paling mudah untuk digunting satu-satu.
Mode "Cerminan per Baris": khusus untuk yang mencetak bolak-balik otomatis menggunakan printer duplex atau membalik tumpukan kertas hasil cetak halaman DEPAN.
Field banyak? Yang dicetak hanya field yang kamu centang di "Field untuk Sisi Depan/Belakang". Jika hasilnya terpotong, kurangi jumlah kolom & baris, gunakan "Ukuran Konten Kartu", atau atur "Posisi Konten dalam Kotak".
Deck besar? Rendering membutuhkan waktu lebih lama — pastikan "Kualitas Gambar" tidak di-set "Original" dan gunakan mode Batch agar print preview tidak freeze.
