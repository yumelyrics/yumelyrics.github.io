+ Background Kartu Opsionalklik untuk buka/tutup▸

Ganti background tampilan kartu di Anki dengan foto sendiri. Berlaku untuk note type - yang sedang dipilih.

Penting jika note type ini sudah dipakai di deck lain yang sudah ada di Anki kamu: Anki hanya memperbarui tampilan note type saat import jika ada perubahan baru yang terdeteksi. Jika setelah import background tetap tidak muncul, hapus dulu deck versi lama dari Anki sebelum import ulang file yang baru.
Video background: Desktop & AnkiDroid butuh format BEDA, gak ada yang overlap:
• Anki Desktop (Windows/Mac/Linux) CUMA bisa muterin video format .webm sebagai background. Kalau dikasih .mp4, background bakal hitam polos (WebView bawaan Anki Desktop gak bisa muter .mp4).
• AnkiDroid (HP Android) CUMA bisa muterin video format .mp4 sebagai background. Kalau dikasih .webm, backgroundnya gak bakal jalan di AnkiDroid.

Jadi gak ada 1 file video yang bisa dipakai bareng buat Desktop & AnkiDroid sekaligus. Kalau kamu belajar di Desktop dan HP sekaligus: upload video .webm di tab 🖥️ Desktop dan video .mp4 di tab 📱 Mobile di bawah (AnkiHoney bakal otomatis matiin "background sama" & naruh video ke tab yang bener pas kamu upload). Kalau cuma mau isi salah satu platform aja, upload video sesuai formatnya masing-masing.
Nonaktif — tab Desktop & Mobile di bawah sekarang masing-masing punya foto/GIF/video sendiri (bukan cuma beda posisi). Isi/upload dulu di tiap tab.
🖼️ Pilih atau seret foto, GIF, WebP animasi, atau video ke sini Foto/GIF/WebP otomatis diproses (animasinya tetap aman); video (disarankan <8MB, tanpa audio) — file .apkg tetap ringan. Video .webm = buat Anki Desktop, video .mp4 = buat AnkiDroid (gak bisa disamain, upload dua-duanya kalau perlu keduanya).
File tersimpan di dalam .apkg sehingga tetap muncul secara offline. Khusus video: frame pertamanya otomatis dijadikan foto fallback yang muncul duluan, lalu videonya fade-in begitu siap dimainkan — jadi gak ada jeda "kosong" sebelum videonya kebaca (tapi kalau formatnya gak sesuai platform tempat kamu belajar -- .mp4 di Desktop atau .webm di AnkiDroid -- background bakal keliatan hitam polos / gak jalan, lihat catatan platform di atas). Jika note type ini sudah dipakai di deck lain yang lebih lama, baca peringatan di atas terlebih dahulu.
Harus tetap online agar background tidak hilang saat dipelajari. Tidak tersimpan ke dalam .apkg (butuh koneksi internet), tapi paling aman karena tidak menyentuh media/note type sama sekali. Khusus video dari link: fallback foto otomatis tidak bisa dibuat (batasan browser), jadi sebelum video main cuma overlay gelap yang keliatan. Ingat juga soal format per platform di atas: link .mp4 gak bakal jalan di Anki Desktop, link .webm gak bakal jalan di AnkiDroid — mode link ini juga gak otomatis dipisah per platform kayak mode upload, jadi pilih salah satu format sesuai platform utama kamu.

Translate Otomatis klik untuk buka/tutup pengaturan ▶

Mode "Jelaskan Kosakata" membutuhkan AI yang dapat memahami instruksi — pilih salah satu dari OpenAI/Claude/Gemini/DeepSeek.

Instruksi ini sama konsepnya dengan "Instruksi Khusus Field" — bedanya AI-nya benar-benar memanggil API & hasilnya langsung ditaruh ke field Tujuan yang kamu pilih di bawah, tanpa perlu copy-paste manual.

Jika field Sumber hanya berisi kosakata tunggal (misal field Kosakata), field ini dapat diisi field lain yang berisi kalimat lengkapnya (misal SentKanji) — isinya HANYA DIBACA dan diberikan ke AI sebagai konteks tambahan.

Yang ditranslate hanya field yang dicentang tapi BUKAN ditandai kunci sumber. API key (jika diisi) hanya tersimpan lokal di browser kamu sendiri, dan teksnya dikirim LANGSUNG dari browser kamu ke server engine yang dipilih (bukan melalui server AnkiHoney).

Field yang mau dihapus:

Export ke PDF — Cetak Flashcard Fisik

Pilih field mana yang masuk ke sisi Depan & Belakang kartu (layout bersih & rapi, tanpa desain asli note type agar tidak berantakan saat dicetak kecil). Disusun jadi grid siap cetak, dibuka di tab baru. Di tab itu ada tombol "Cetak / Save as PDF" — klik jika sudah siap.

Kartu akan disusun otomatis sebanyak yang muat per halaman sesuai ukuran ini.

Mode "Samakan Posisi" (default): tiap kartu di halaman belakang ada di posisi grid yang SAMA dengan di halaman depan — paling mudah untuk digunting satu-satu.
Mode "Cerminan per Baris": khusus untuk yang mencetak bolak-balik otomatis menggunakan printer duplex atau membalik tumpukan kertas hasil cetak halaman DEPAN.
Field banyak? Yang dicetak hanya field yang kamu centang di "Field untuk Sisi Depan/Belakang". Jika hasilnya terpotong, kurangi jumlah kolom & baris, gunakan "Ukuran Konten Kartu", atau atur "Posisi Konten dalam Kotak".
Deck besar? Rendering membutuhkan waktu lebih lama — pastikan "Kualitas Gambar" tidak di-set "Original" dan gunakan mode Batch agar print preview tidak freeze.
